# 🎬 Movie Booking System

A full-stack movie ticket booking web application that allows users to browse movies, select theatres, choose dates and showtimes, select seats, make payments, and receive a booking confirmation with an e-ticket.

## 🚀 Features

- 🎬 Browse and select movies
- 🏢 Select theatre
- 📅 Select booking date
- 🕐 Select showtime
- 💺 Interactive seat selection
- 💳 Payment page
- ✅ Booking confirmation
- 🎟️ E-ticket generation
- 📱 Responsive user interface

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- CORS
- dotenv
